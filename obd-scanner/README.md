# فاحص 🚗

تطبيق ويب يُثبَّت على الجوال (PWA) لقراءة أعطال السيارة ومسحها ومتابعة بياناتها المباشرة، عبر محوّل **ELM327 بلوتوث BLE** يركّب في منفذ OBD2.

لا خادم ولا حسابات ولا تتبّع: التطبيق يتكلم مع السيارة مباشرة من المتصفح، ويعمل بدون إنترنت بعد أول فتح.

## الميزات

| القسم | ما يفعله |
|---|---|
| **الأعطال** | قراءة الأعطال المؤكَّدة (Mode 03) والمعلّقة (07) والدائمة (0A)، مع وصف عربي ودليل للأعطال الشائعة (الأسباب، الخطورة، ماذا تفحص أولاً)، ومسح الأعطال (04) بعد تأكيد وتحذيرات |
| **مباشر** | قراءات حيّة قابلة للتخصيص (الدوران، السرعة، حرارة الماء والزيت، الحِمل، تصحيح الوقود، MAF، MAP…)، وتسجيل وتصدير CSV، و**تحليل خليط الوقود** الذي يميّز تسريب الفاكيوم عن ضعف ضخ الوقود |
| **الرحلة** | الاستهلاك اللحظي والمتوسط، المسافة، الوقود المستهلك، تكلفة الرحلة، ومؤقّت 0–100 |
| **فحص الشراء** | يكشف مسح الأعطال الحديث قبل البيع: جاهزية أنظمة المراقبة، المسافة والوقت ودورات الإحماء منذ آخر مسح، والأعطال الدائمة، ثم حكم واضح |
| **الرئيسية** | رقم الهيكل VIN، البروتوكول، جهد البطارية وتفسيره، حالة لمبة فحص المحرك |
| **وضع التجربة** | سيارة محاكاة كاملة لتجربة كل شيء بدون سيارة |

## المتطلبات

- محوّل ELM327 يدعم **BLE** (مثل vLinker و OBDLink CX و Veepeak BLE وكثير من النسخ ذات خدمة FFF0/FFE0). المحوّلات التي تعمل بالبلوتوث الكلاسيكي فقط (SPP) لا يمكن للمتصفح الوصول إليها.
- **أندرويد:** Chrome. **الكمبيوتر:** Chrome أو Edge. **آيفون:** Safari لا يدعم Web Bluetooth، فاستخدم متصفحاً يدعمه مثل Bluefy.
- يعمل التطبيق من `https` أو `localhost` فقط (شرط في Web Bluetooth).

## التشغيل

```bash
cd obd-scanner
npm test          # 21 اختباراً: محلّل البروتوكول + تشغيل كامل على المحاكي
npm run serve     # ثم افتح http://localhost:8080
```

لا توجد مكتبات خارجية ولا خطوة بناء. للنشر ارفع المجلد كما هو على أي استضافة ثابتة بـ https (مثل GitHub Pages)، ثم من Chrome على الجوال اختر «إضافة إلى الشاشة الرئيسية».

## البنية

```
src/elm327.js         بروتوكول ELM327: طابور أوامر متسلسل، مهلات وإعادة مزامنة، تجميع رسائل ISO-TP متعددة الإطارات، فك VIN والأعطال
src/pids.js           تعريف قراءات SAE J1979 وفك حالة المراقبة (Mode 01 PID 01)
src/dtc-db.js         قاعدة وصف الأعطال بالعربية + أدلة الأعطال الشائعة
src/analysis.js       تحليل الخليط، حكم فحص الشراء، حساب الاستهلاك، مؤقّت 0–100 (دوال نقية مختبرة)
src/transport-ble.js  نقل Web Bluetooth
src/transport-sim.js  محاكي محوّل + سيارة (CAN 11/500)
src/app.js            الواجهة
sw.js                 عمل بدون إنترنت
```

## الأمان

- سياسة CSP صارمة: لا سكربتات خارجية، ولا اتصال بأي خادم.
- كل النصوص تُدرج بـ `textContent`، ولا يُستخدم `innerHTML` مع أي بيانات.
- البيانات الوحيدة المحفوظة على الجهاز: القراءات المختارة وسعر الوقود.

## ما لا يفعله التطبيق (عن قصد)

- **برمجة وحدات السيارة (Coding) وإعادة ضبط الخدمات** (الزيت، فرامل اليد، DPF…): هذه أوامر خاصة بكل شركة وموديل، والكتابة الخاطئة قد تعطّل وحدة في السيارة. لا تُضاف إلا لموديلات محددة بعد اختبارها على سيارات حقيقية.
- أعطال ABS والوسائد والهيكل: تحتاج عناوين وبروتوكولات خاصة بكل شركة. التطبيق يقرأ أعطال المحرك والقير القياسية.
